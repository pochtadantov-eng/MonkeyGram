# MonkeyGram

Визуальный Telegram-подобный клиент для игры с подарками, Stars и TON.

## Возможности

- Интерфейс в стиле Telegram: чаты, переписка, профили, настройки
- **Настройки → Визуальные функции**
  - включить визуалку (кнопка «Отправить подарок» в профиле)
  - включить баланс Stars / TON, ввести суммы и сохранить (не сбрасываются)
- Покупка визуальных подарков и NFT за Stars / TON
- История пополнений и трат отдельно для Stars и TON

Всё хранится локально в `localStorage`. Реальные платежи Telegram не выполняются.

## Запуск

```bash
cd web
npm install
npm run dev
```

Сборка:

```bash
cd web
npm run build
```
